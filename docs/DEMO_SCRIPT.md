# Demo Script

Run through these five steps in order during the demo. Each step demonstrates a distinct part of the product.

1. Ask the bot (on WhatsApp) for a brand's official number — for example, send "Zomato care number". Show the reply with the official number, source link, and last-checked date.
2. Send a fake number to the bot. Show the High-risk reply: verdict, reasons, report count, and the cybercrime.gov.in / 1930 advisory. Show that the reply includes a link to the website.
3. Open the detail link from the bot reply on the website. Show the number detail page: verdict, reasons, report count, and the brand's official number if known.
4. Submit a scam report on the website using the report form.
5. Re-check the same fake number on WhatsApp. Show that the report count has increased, demonstrating that the website and bot share the same live database.
